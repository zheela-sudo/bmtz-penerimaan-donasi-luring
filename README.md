## 📌 Deskripsi Singkat
Repositori ini berisi dokumen **Software Requirements Specification (SRS)** untuk **Subsistem Penerimaan Donasi Luring BMTZ**. Subsistem ini dirancang dengan pendekatan *offline-first* untuk mencatat transaksi penerimaan donasi (tunai, QRIS, kartu) pada kegiatan booth/event yang memiliki keterbatasan atau ketidakstabilan koneksi internet.
